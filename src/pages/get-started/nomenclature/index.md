# Common UXP Plugin Terms

Plugin, panel, command, manifest, entry point, script, and host have the same meanings across all UXP-enabled Adobe applications. The UXP Hub maintains the canonical terminology and its mapping from CEP and ExtendScript.

<DiscoverBlock slots="link, text"/>

[Read Common Plugin Terms](https://developer-stage.adobe.com/uxp/guides/explanation/fundamentals/nomenclature/?aio_external)

Learn the vocabulary used throughout UXP documentation and how older extensibility terms map to the current plugin model.

## Media Encoder Context

In these docs, **Media Encoder** is the host. A Media Encoder plugin combines the shared UXP runtime and APIs with the [Media Encoder API](../../media-encoder-api/index.md).
