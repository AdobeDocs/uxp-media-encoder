# Start with the UXP Developer Journey

UXP Hub is the canonical home for knowledge shared by every UXP-enabled Adobe application. Start there if you are new to UXP, then return to these docs for Media Encoder setup, samples, and host APIs.

## What to Learn in UXP Hub

Follow the shared journey in the order that matches your experience:

<DiscoverBlock slots="link, text"/>

[Get Oriented](https://developer-stage.adobe.com/uxp/guides/?aio_external)

Understand the UXP platform, development loop, available learning paths, and how shared APIs work with host APIs.

<DiscoverBlock slots="link, text"/>

[Set Up Your Developer Tools](https://developer-stage.adobe.com/uxp/guides/how-to/developer-tools/?aio_external)

Install the UXP Developer Tool and a code editor, enable UDT Developer Mode, and learn the edit-reload-debug workflow.

<DiscoverBlock slots="link, text"/>

[Learn Plugin Concepts](https://developer-stage.adobe.com/uxp/guides/explanation/?aio_external)

Learn how manifests, entry points, panels, commands, lifecycle hooks, and supported UI capabilities fit together.

<DiscoverBlock slots="link, text"/>

[Build and Debug Plugins](https://developer-stage.adobe.com/uxp/guides/how-to/?aio_external)

Use task-focused guides and recipes for common plugin work, then debug the result with UDT.

<DiscoverBlock slots="link, text"/>

[Package and Publish](https://developer-stage.adobe.com/uxp/guides/how-to/distribution/overview/?aio_external)

Package your plugin, prepare a Marketplace listing, or distribute it independently or within an enterprise.

## Continue with Media Encoder

When you understand the shared workflow, [set up Media Encoder](../developer-tools/index.md), build your first host-specific plugin, and use the Media Encoder API for render queues, jobs, presets, and progress reporting.

Already comfortable with UXP? Skip directly to [Set Up Media Encoder](../developer-tools/index.md).
